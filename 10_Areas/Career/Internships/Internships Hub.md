# Internships Hub
==This folder is reference: research on companies, people, and methods that stays true regardless of where any single application currently stands.== Live status, drafts, and prep live in `20_Progress/Internship/` instead — see [[30_Order/Workflows/Internship Pipeline]] for the full flow between the two.
## What's Here
- **`List/`** — monthly capture logs of every posting found. Firehose tier, no commitment implied.
- **`Programs/`** — one deep-dive note per program you've committed to pursuing. Static research only: comp, eligibility, deadlines, traps.
- **`Contacts/`** — one note per person, durable facts plus the current live draft to them. `Mimic.md` holds the reusable message templates.
- **`Cheats/`** — methods and tactics that actually worked, added as they're proven, not designed in advance.
- **`Tracker/`** — the two dashboard views: `Internship - Dashboard.md` (detailed, Dataview) and `Tracker.md` (kanban, at-a-glance).
## Where The Live Work Is
`20_Progress/Internship/` holds everything that changes week to week: `Applying/` (live status per program), `Interviews/` (prep per company), `Resumes/` (the bullet bank and tailored cuts), `Posts/` (LinkedIn drafts).
## Why The Split
A Program note that also carries a status field gets rewritten every time you hear back — that defeats the point of Areas being durable. [[30_Order/Workflows/Internship Pipeline]] explains the mechanism in full; this note is the entry point, not the explanation.
## Scope
Built internship-first but role-type-agnostic — the same List/Programs/Contacts/Cheats structure is meant to carry a full-time job search later without renaming or restructuring.
