## Your responsibilities
**How You Will Contribute and What You Will Learn**
- Build and extend agentic AI pipelines using Google ADK, LangChain, and LlamaIndex — including multi-tool agents that reason over internal system specifications.
- Develop ETL pipelines that extract, parse, and index internal documents (requirements, user scenarios) from internal database into OpenSearchvector stores.
- Implement RAG (Retrieval-Augmented Generation) systems using OpenSearch vector search and Vertex AI Search to power semantic search over telecommunications documentation.
- Contribute to FastAPI backend services and Next.js/React frontend components for AI-powered tools used by 5G architects and engineers.
- Work with LLMs on Google Cloud Vertex AI (Gemini models) for structured output generation, Cypher query generation, and document summarization.
- Participate in Agile sprints with code reviews, documentation, and CI/CD via GitLab pipelines.
## Your skills and experience
**Qualifications**
- Legal authorization to work in the United States without sponsorship.
- Proficiency in Python and TypeScript/React.
- Exposure to Artificial Intelligence, NLP, or LLM-based applications.
- Experience with Linux, Git/GitLab, and command-line development.
- Understanding algorithms, data structures, and REST APIs.
- Experience with AI coding assistants (GitHub Copilot, Cursor, Claude, etc.).
- Strong communication and problem-solving skills.
- Experience with Visual Studio Code.
- Google Cloud Platform experience.
**It Would Be Nice If You Also Had**
- Docker and cloud deployment .
- Knowledge of SQL and databases.
- Familiarity with Agile development.
- LangChain/LlamaIndex for LLM applications.
