Copart Tech – Test Automation Team is looking for an Intern with a strong foundation in TypeScript and/or Java. Developer/Programmer for the SDET role with strong Academic or Organizational or Type Script or Java developer boot camp experience. Learn quickly and be productive in a highly collaborative, lightning-fast environment.
**Requirements:**
- Proven TypeScript and/or Java experience with a firm grasp of object-oriented analysis and design (OOAD).
- A strong drive to write clean, simple, and efficient test automation code for both UI and RESTful web services.
- Solid ability to translate user stories into comprehensive test cases and scenarios, alongside a good understanding of TDD and BDD best practices.
- Good understanding of browser rendering behavior and front-end performance.
- Familiarity with relational databases (MariaDB preferred but not mandatory).
- Front-end web development skills, including HTML, CSS, and ReactJS is a plus.
- Prior hands-on experience with Test Automation Frameworks and tools (especially Playwright) is a plus.
- Having multi lang programming skills (like Python) is an added advantage but not must.
- Good written and communication skills.
