- San Jose, CA, USA · Intern · Non-Exempt · Salary Range: $34.52-$46.00 · Business Function: Engineering Support · Work Location: San Jose Great Oaks Headquarters

**Company Description**

WD is building the infrastructure behind the AI-driven data economy. As AI scales, so does data. Every interaction, every model, every system generates data that must be stored, managed, and made accessible over time. WD combines deep engineering expertise with global-scale manufacturing to deliver the storage systems that make AI possible, powering hyperscale data centers, cloud platforms, and enterprise infrastructure worldwide.

**Job Description**

*This posting supports current and anticipated early-career hiring needs. Applying allows the recruiting team to consider you for opportunities that align with your qualifications, preferences, and availability. An immediate opening or interview is not guaranteed.*

Roles may work with teams in: Colorado Springs CO, Irvine CA, Longmont CO, Fremont CA, Rochester MN, San Jose CA.

**System Tools Software Intern** — Build the software behind the technology. Design, develop, test, and improve tools that make systems faster, more reliable, and easier to build. May: design/develop system software, utilities, engineering tools; build or enhance operating systems, compilers, networking tools, databases, internet-based applications; troubleshoot/debug/optimize software performance; collaborate with hardware and software engineers on integration; help influence hardware design via efficient software.

**Applications Software Intern** — Create software that helps teams work smarter. Design, build, test, and improve software used across enterprise systems. May: design/develop/maintain commercial and internal software applications; write clean, efficient, maintainable code; test/debug/improve performance; collaborate on new features; create deployment/maintenance documentation.

**Data Analytics Intern** — Turn data into insights that drive better decisions. Build tools and data systems that help teams understand performance and solve business challenges. May: design/develop data pipelines, databases, data warehouses; build automation tools for collecting/processing/analyzing data; create dashboards/reports/visualizations; partner with stakeholders to translate business needs into technical solutions; analyze data for trends and process improvement.

**Firmware Engineering Intern** — Write the code that brings hardware to life. Develop low-level software enabling hardware devices to function; work at the hardware/software intersection on reliable, high-performance embedded systems. May: design/develop/test/debug embedded firmware; write C, C++, assembly, and other low-level code; collaborate with hardware engineers on integration; troubleshoot firmware/hardware interactions; support new product development from concept through production. Part of WD's early career development program (structured onboarding, mentorship, curated curriculum; ~0-2+ years relevant experience targeted, all experience levels encouraged to apply).

**Systems Design & Integration Intern** — Bring complex systems together. Ensure hardware and software work together seamlessly across engineering teams. May: define system requirements/technical specifications; evaluate hardware/software compatibility; coordinate integration of multiple subsystems; identify/troubleshoot/resolve system-level issues; recommend performance/reliability/scalability improvements.

**Qualifications**

Required:
- Currently pursuing a Bachelor's or Master's degree in Computer Science, Software Engineering, Computer Engineering, Systems Engineering, Data Science, Electrical Engineering, or a related technical field.
- Experience developing technical skills through coursework, internships, research, or personal projects using one or more of: C, C++, Python, Java, Go (Golang), SQL, JavaScript, or similar.
- Familiarity with software development fundamentals, debugging, data structures, algorithms, operating systems, or other computer engineering concepts.
- Strong analytical, critical thinking, and problem-solving skills with a passion for learning new technologies.
- Excellent written and verbal communication skills; ability to collaborate effectively in a team environment.
- Proficiency with Microsoft Office and common dev tools (Git, Linux, IDEs) is a plus.
- Interest in storage technologies, semiconductors, embedded systems, cloud computing, AI, data analytics, or other emerging technologies.

Anticipated application deadline: 10/20/26 (WD reserves the right to close sooner if a hire is made before the deadline).
