# Position Summary:
Dee Zee is seeking a Summer 2027 Intern to join our Software Development team! This internship will run approximately June 1 through September 3, 2027, with flexibility to adjust the start and end dates based on the selected candidate’s availability.
The Software Development Intern will assist with the design, testing and support of business applications in a manufacturing environment. This internship offers hands-on experience with modern development tools, databases and system integrations, while providing exposure to real-world software projects that support core business operations.
# Accountabilities:
- Assist in developing, testing, and debugging software applications.
- Support system integrations between business applications.
- Help maintain and update SQL Server databases and reporting tools.
- Participate in code reviews, documentation, and source control activities.
- Collaborate with team members to troubleshoot issues and provide technical support.
- Contribute to small-scale projects and enhancements that improve business efficiency.
# Qualifications:
- Pursuing a degree in Computer Science, Software Engineering, Information Systems, or a related technical field.
- Familiarity with programming languages such as C#, VB.NET, or JavaScript.
- Understanding of relational databases and SQL (Microsoft SQL Server preferred).
- Strong problem-solving and analytical skills with attention to detail.
- Ability to learn quickly and work independently or as part of a team.
- Proficiency in Microsoft Office; experience with Visual Studio, Azure DevOps, or Git is a plus.
- Interest in software development within a manufacturing or business systems environment.
