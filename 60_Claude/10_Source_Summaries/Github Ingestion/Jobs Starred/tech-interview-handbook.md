# Tech Interview Handbook

**GitHub:** [yangshun/tech-interview-handbook](https://github.com/yangshun/tech-interview-handbook) | **Stars:** 140k | **Updated:** Apr 5, 2026

## What it is
A curated interview prep guide — not a problem dump — covering the full arc from applying to offer negotiation. Created by the author of Blind 75. The repo backs a website at [techinterviewhandbook.org](https://www.techinterviewhandbook.org/). Key artifacts: Grind 75 (a time-parameterized successor to Blind 75), algorithm topic cheatsheets, a resume guide aimed at FAANG formatting, and a behavioral question bank.

## How Anant uses it
Specific sections by use case:

- **Building a study plan:** Use [Grind 75](https://www.techinterviewhandbook.org/grind75/) — it generates a filtered problem list by time budget (1 week / 4 weeks / 8 weeks) and difficulty. Better starting point than random LeetCode for structured prep.
- **Pre-interview day-of review:** Algorithm cheatsheets at [techinterviewhandbook.org/algorithms/study-cheatsheet](https://www.techinterviewhandbook.org/algorithms/study-cheatsheet/) — concise time/space complexity tables by topic. Read the array, tree, graph, and DP sheets the morning of an interview.
- **Resume:** The [resume guide](https://www.techinterviewhandbook.org/resume/) explains FAANG-style bullet formatting (action verb + metric + tech). Use it when rewriting the resume before Fall 2026 recruiting.
- **Behavioral prep:** The [behavioral questions section](https://www.techinterviewhandbook.org/behavioral-interview-questions/) covers what FAANG and top companies actually ask. Build STAR stories from UMN coursework and projects against these specific questions.

Does NOT cover system design — the site explicitly redirects to ByteByteGo for that.

## How to install / run it (Windows)
Use the website (techinterviewhandbook.org), not the GitHub repo directly. The website has better navigation. Bookmark the Grind 75 tool and the algorithm cheatsheets page.

## Caveats / current state
- Actively maintained; last commit Apr 2026, site repo updated March 2026.
- Front-end content was split off to frontendinterviewhandbook.com — if Anant targets frontend roles, check there separately.
- Grind 75 skews toward FAANG-style interviews; quant-focused companies (Jane Street, Citadel) have different problem patterns not well-covered here.
- No system design content — acknowledged gap; use system-design-primer for that.
- The course recommendations (AlgoMonster, Design Gurus) are affiliate links — skip them unless you've decided to pay for a course.
