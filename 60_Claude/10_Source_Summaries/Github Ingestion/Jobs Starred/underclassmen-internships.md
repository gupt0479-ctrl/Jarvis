# Underclassmen Internships

**GitHub:** [zapplyjobs/underclassmen-internships](https://github.com/zapplyjobs/underclassmen-internships) | **Stars:** 1.3k | **Updated:** Jun 19, 2026

## What it is
A curated list of internships, externships, fellowships, and winternships gated to CS freshmen and sophomores — programs where being an underclassman is not a disqualifier but sometimes a requirement. Maintained by Zapply, updated for 2026.

## How Anant uses it
Anant is a sophomore, which is exactly who this list targets. Specific use cases:

- **Fellowships to apply this fall:** MLH Fellowship (open year-round, stipend available), SEO Tech Developer (Sophomore-specific, 6-week immersion), Salesforce Futureforce Tech Launchpad, CodePath SITE. These are the easier path to internship experience when top-tier SWE internships are tough to get as a sophomore.
- **Externships for quant/finance exposure:** Jane Street SEE, SIG Discovery Day, Discover Citadel — these are 1–3 day programs that lead directly to internship pipelines. Apply October–November for programs running in spring.
- **Internship-matching fellowships if direct applications stall:** Kleiner Perkins Fellows, 8VC Fellowship, Neo Scholar — these match students to startup internships and are worth a shot if FAANG SWE apps don't convert.
- **Winternships as a gap-filler:** HRT Women in Trading Tech (if applicable), Impact Labs Fellowship (2 weeks NYC, December).

## How to install / run it (Windows)
Bookmark the repo. Check it each August–September when fall programs open. Most programs in the table have `?` for status, meaning you need to verify directly — the open/close dates are not updated daily. Cross-check each program's website before applying.

## Caveats / current state
- Open/close statuses are **not updated daily** — the repo acknowledges this explicitly. Many rows show `?`. Always verify on the company's site.
- List covers programs that have existed historically; some may be discontinued for 2027.
- Zapply is a job autofill Chrome extension — some entries push you toward their platform. The list itself is still useful independently.
- Most fellowships in the table are US-based; some have diversity eligibility criteria.
