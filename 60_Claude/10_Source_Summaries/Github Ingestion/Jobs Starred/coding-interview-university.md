# Coding Interview University

**GitHub:** [jwasham/coding-interview-university](https://github.com/jwasham/coding-interview-university) | **Stars:** 354k | **Updated:** Dec 2024

## What it is
A multi-month self-study curriculum covering the CS fundamentals needed to pass SWE interviews at large companies — data structures, algorithms, OS concepts, networking, and more. Created by someone who studied 8–12 hours/day for several months before landing at Amazon. It's a checklist-style plan, not a problem set.

## How Anant uses it
The plan is structured as a checklist with video/reading resources per topic. For a sophomore who already has CSCI 1913 and 2033 under his belt, the most immediately useful sections are:

- **Data Structures** — Arrays, Linked Lists, Stack, Queue, Hash tables. Use this to fill gaps before OA season starts, not to learn from scratch.
- **Trees and Graphs** — The tree section (BFS/DFS, binary search trees, tries) and graph section (Dijkstra, union-find) cover the patterns that show up most in SWE internship OAs.
- **Algorithmic Complexity / Big-O** — Even if you know this from coursework, the section has good mental models for communicating complexity out loud during interviews.
- **Sorting algorithms** — The repo's sorting section is a good one-time review; you won't be asked to implement merge sort but you need to reason about it.

**What to skip for internship hunting:** The OS internals section (process scheduling, virtual memory), networking deep dives, compilers, and system design. These are more relevant for full-time/new-grad interviews at Google/Amazon than for sophomore internship OAs.

## How to install / run it (Windows)
Use the README.md on GitHub. Fork the repo and check off items as you complete them (the checkboxes are in Markdown and work when you edit your fork). Or just use the TOC as a reading list without forking.

## Caveats / current state
- Last real content update: December 2024 (about 18 months ago). The content is still accurate for CS fundamentals but is not maintained for current interview trends.
- The plan was designed for a full-time student spending months studying. For Anant with a course load, use the topical index selectively rather than following the sequence start-to-finish.
- Skews toward Amazon/Google/Microsoft interview patterns; quant shops (Jane Street, Two Sigma) have different problem types not well-represented here.
- Tech Interview Handbook's Grind 75 is a more efficient starting point for time-constrained interview prep; use CIU as a supplement when you hit a conceptual gap.
