# LeetCode Company-wise Interview Questions

**GitHub:** [snehasishroy/leetcode-companywise-interview-questions](https://github.com/snehasishroy/leetcode-companywise-interview-questions) | **Stars:** 5.6k | **Updated:** May 2026

## What it is
A flat-file repo organized by company name (folders: `amazon/`, `google/`, `meta/`, `jane-street/`, etc.), each containing a list of LeetCode problem IDs and titles asked at that company as of May 24 2026. Java solutions are included for some problems, but the primary value is the problem list itself. Updated regularly — the last update captured May 2026 company interview data.

## How Anant uses it
When targeting a specific company for Summer 2027 internship applications: navigate to that company's folder, extract the problem list, and grind those problems on LeetCode in Python. The repo itself does not have Python solutions — use it to identify which problems to target, then solve on LeetCode (with NeetCode.io as a solution reference for Python). Priority order: target company list → filter by frequency/difficulty → solve in NeetCode order within that set.

For quant internships (Jane Street, Citadel, Two Sigma): their folders contain the most relevant problems; these skew heavily toward dynamic programming, graph algorithms, and combinatorics.

## How to install / run it (Windows)
No install needed — browse GitHub directly. Clone if you want to use grep/search across all company folders to find which companies ask a specific problem.

## Caveats / current state
Java solutions only — the repo does not contain Python code. The problem list is language-agnostic, but if you want worked solutions you need NeetCode, LeetCode editorial, or your own code. The May 2026 update makes this one of the freshest company-wise resources available. A comparable alternative is the NeetCode company-wise filter, but this repo updates more frequently. The data comes from community-reported interviews, not official sources — treat it as a strong signal, not a guarantee.
