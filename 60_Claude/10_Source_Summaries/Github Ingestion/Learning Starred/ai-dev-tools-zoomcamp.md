# AI Dev Tools Zoomcamp

**GitHub:** [DataTalksClub/ai-dev-tools-zoomcamp](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp) | **Stars:** 1.1k | **Updated:** June 2026

## What it is
A 6-module free course from DataTalksClub covering how to use coding assistants (Claude Code, Cursor, Copilot), MCP servers, custom coding agents, AI for CI/CD, and n8n automation — structured as pre-recorded videos with graded homework during live cohorts and self-paced otherwise.

## How Anant uses it
- **Module 3 (MCP)** is the highest-priority module: covers GitHub, filesystem, DB/SQL, and HTTP/API servers with practical workflows for repo triage and data queries — directly maps to how Jarvis MCP servers are configured. Do this module when setting up a new MCP server or debugging permissions.
- **Module 4 (Build a Coding Agent)** applies to Kronos: the module builds an agent that scaffolds and extends Django projects using multiple orchestration frameworks. Read it when deciding how to wire Kronos's agent loop.
- **Module 5 (AI for CI/CD)** applies to the trading AI repo: covers automated test generation, LLM evals in CI, and PR review automation — useful when TradingAgents gets far enough to need a CI pipeline.
- Module 6 (n8n) is lowest priority for current projects but relevant if Jarvis needs no-code automation triggers.

## How to install / run it (Windows)
Self-paced: browse the GitHub repo directly, watch the YouTube playlist, and do homework exercises locally. Next live cohort is 2026 (date TBA as of June 2026) — register at airtable.com/appJRFiWKHBgmEt70/shrpw7rk55Ewr1jCG to be notified. No install required — course materials are notebooks and markdown in the repo.

First cohort ran November 2025; second cohort scheduled for 2026 but no date confirmed as of this writing. The course is actively maintained (last commit June 2026). MCP content in Module 3 reflects the current MCP ecosystem. Prerequisites: basic Python or JS proficiency; no prior AI experience required.
