# Project-Based Learning

**GitHub:** [practical-tutorials/project-based-learning](https://github.com/practical-tutorials/project-based-learning) | **Stars:** 266k | **Updated:** actively maintained

## What it is
Curated list of project-based tutorials where you build something real while learning a technology. Organized by language: C, C++, Java, Python, Go, Ruby, JavaScript, Rust, and more. Each entry links to a full tutorial — building a web server, a shell, a database, a game, an OS kernel, etc. Focus is on "learn by building X from scratch" rather than following isolated exercises.

## How Anant uses it
Reference when learning a new language or technology where the best approach is to build something end-to-end rather than read docs. For the trading project: Python + async, Python + websockets, and Rust tutorials here are directly applicable when Anant needs to build a custom component from scratch rather than wire together libraries.

Higher-value than freeCodeCamp for Anant's current level — these are tutorials for building non-trivial things, not intro exercises.

## How to install / run it (Windows)
No install — it's a curated link list. Browse the README by language or use `Ctrl+F` for the technology.

## Caveats / current state
Link-list format means quality is entirely dependent on the linked tutorials, which vary from excellent to abandoned. Tutorials age — check the linked repo's last commit date before investing time. Python section is large but the best Python tutorials on this list tend to be "build your own X" style (web framework, ORM, async event loop) not beginner Python. JavaScript section is also large. The Rust section is smaller but high-quality.

**Verdict: yes** — reference when starting work on a new technology that would benefit from a full build-it-yourself tutorial. More aligned with Anant's level than the freeCodeCamp exercises.
