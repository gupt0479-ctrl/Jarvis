# Awesome LLM Apps

**GitHub:** [Shubhamsaboo/awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps) | **Stars:** 116k | **Updated:** June 14, 2026 (active)

## What it is
Curated collection of working LLM app examples built with Agno, OpenAI, Anthropic, Gemini, and other providers. Organized by domain: finance agents, research agents, RAG apps, multi-agent systems, customer support, coding agents. Each folder has a complete runnable project with a README.

## How Anant uses it
Use as a pattern library when starting a new agent project — search the repo for the closest existing example rather than designing from scratch. Most relevant categories: finance agents (trading/Kronos direction), multi-agent research (autoresearch pattern), RAG apps (Jarvis search extension ideas).

Run: `git clone`, navigate to the closest example, read the structure before adapting.

## How to install / run it (Windows)
No install — it's a collection, not a package. Each subfolder has its own `requirements.txt` and README. Most examples require an API key (Anthropic or OpenAI).

## Caveats / current state
116k stars as of June 2026, actively updated. Quality varies across examples — some are tutorials, some are production-level. The Agno framework appears heavily in recent examples; Agno is Phidata's rebranding, so existing knowledge applies. Not all examples have been updated for latest API versions.

**Verdict: yes** — first stop for "does a working example of X already exist?" Use the GitHub search to find specific patterns (`site:github.com Shubhamsaboo/awesome-llm-apps <topic>`).
