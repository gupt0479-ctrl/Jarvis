# Build Your Own X

**GitHub:** [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) | **Stars:** 520k | **Updated:** actively maintained

## What it is
Curated list of step-by-step tutorials for building core technologies from scratch: databases, operating systems, browsers, git, compilers, shell, web servers, neural networks, and more. Organized by technology and programming language. Each entry links to a full tutorial — not descriptions, actual implementations.

## How Anant uses it
Go-to reference when encountering a technology where understanding the internals would close a conceptual gap. For the trading project: build-your-own neural network tutorials deepen understanding of how model training actually works. For systems interviews: building a minimal shell or DB from scratch is better interview prep than reading about them.

Pick one project that's directly relevant to something Anant is working on, build it once end-to-end. Don't browse — search for the specific technology.

## How to install / run it (Windows)
No install — it's a curated link list. Choose the target technology, pick the language, follow the linked tutorial.

## Caveats / current state
Actively maintained via community PRs. Quality varies widely by tutorial — some are excellent step-by-step guides, others are incomplete. The list focuses on foundational technologies (OS, DB, compiler), not current AI/ML tools. Tutorials age out as APIs change; check the linked repo's last commit date before investing time.

**Verdict: yes** — reference when you want to build something foundational rather than just use it. Not a curriculum.
