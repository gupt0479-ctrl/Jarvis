# App Ideas Collection

**GitHub:** [florinpop17/app-ideas](https://github.com/florinpop17/app-ideas) | **Stars:** 95.3k | **Updated:** Oct 2025 (essentially frozen)

## What it is
94 app project specs organized into three tiers by difficulty: Tier 1 (Beginner) — 35 small UI/utility apps; Tier 2 (Intermediate) — 32 apps requiring APIs and development tools; Tier 3 (Advanced) — 20 apps with backend and database components. Each project has a clear objective, user stories, and bonus features. No code — just structured specs.

## How Anant uses it
Reference when starting a new side project with "no idea what to build." The Tier 2/3 specs (GitHub Profiles, chat app, movie app with rating/actor data) are the most directly useful for a CS sophomore's portfolio — they require external APIs but aren't trivially simple. The user stories format makes each spec immediately actionable for Claude Code prompting.

The structured user stories are directly usable as `/speckit.specify` input.

## How to install / run it (Windows)
No install. Browse the `Projects/` folder or the README table.

## Caveats / current state
Essentially frozen since Oct 2025. The projects are frontend-focused (JavaScript, CSS, HTML heavy). Tier 1 projects are too trivial for a portfolio. The "plans for a website" mentioned in the README were never built. No AI/ML projects in the collection — these are traditional web apps.

**Verdict: yes** — reference when portfolio project brainstorming stalls. Tier 2/3 are the right target difficulty for sophomore-level portfolio work.
