# 500 AI/ML Projects

**GitHub:** [ashishpatel26/500-AI-Machine-learning-Deep-learning-Computer-vision-NLP-Projects-with-code](https://github.com/ashishpatel26/500-AI-Machine-learning-Deep-learning-Computer-vision-NLP-Projects-with-code) | **Stars:** 35k | **Updated:** Aug 2025

## What it is
Curated list of ~103 entries linking to external repos, Medium articles, and tutorials covering ML, DL, computer vision, NLP, and time series. Each row is a link to a collection (e.g., "10 ML Projects on Time Series Forecasting") rather than a single project. It's a meta-index — a list of lists.

## How Anant uses it
Use as a starting point when exploring a new ML domain for the first time. For example, before starting a time series forecasting component of the trading project, check row 4 ("10 ML Projects on Time Series Forecasting") for existing implementations. The NLP rows (#23, #38, #83) are useful for natural language components of trading/financial analysis agents.

Not a curriculum — scan the rows for the specific domain needed, then follow the linked resource.

## How to install / run it (Windows)
No install — it's a link list. Each linked resource has its own setup.

## Caveats / current state
Many of the linked articles are on Medium behind paywall. Several linked repos are from 2019–2021 and use deprecated APIs (TensorFlow 1.x, PyTorch pre-2.0). The "more coming" promise at the bottom has been stale for 2+ years. Actively maintained in the sense that bad links get reported and fixed, but new content is sparse since 2022.

**Verdict: partial** — scan the rows when exploring a new ML domain, but don't use as a primary learning resource. Many links will be outdated.
