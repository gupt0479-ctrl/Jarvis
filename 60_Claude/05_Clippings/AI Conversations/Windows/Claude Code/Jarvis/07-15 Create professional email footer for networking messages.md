## Step 1: Match the visual style

This is Gmail's **native rich-text signature editor** — no HTML coding required. Here's how to build it directly:

## Step 2: Build it in Gmail Settings

1. Open Gmail → gear icon (top right) → **See all settings**
2. Scroll to the **Signature** section → click **Create new** → name it (e.g. "Networking")
3. In the signature box, type your content in plain form first, e.g.:
   ```
   Best,

   Anant

   --
   Anant Gupta
   [Your year] at UMN CSE
   [Your major/minor if any]
   mobile: [your number]
   email: [your email]
   ```
4. Now style it using Gmail's built-in toolbar (the small **A** icon at the bottom of the signature box expands formatting options: font, size, color, bold, italic):
   - Select your **name line** → set font to **Serif**, size **Large**, click **Bold**, then set text color to a gray (Gmail's palette has a medium gray — pick that, avoid pure black)
   - Select the **role/status line** (e.g. "4th year at UMN CSE") → same gray, **Bold**, size Normal/Small
   - Select the **major/minor line** → same gray, *Italic*, not bold
   - For **mobile:** and **email:** lines — bold just the label word, leave the value in regular weight, same gray
   - The email address: Gmail auto-links it, or highlight it and use the **Insert link** icon, set to `mailto:youremail@umn.edu`
5. Click **Save Changes** at the bottom of Settings.

## Step 3: Where it applies

- Under the same Signature section, set which signature is used for **new emails** vs **replies/forwards** (I'd recommend using it on new emails, and optionally a shorter version on replies so threads don't get cluttered)

## Step 4: Test it

Send yourself a test email and check rendering on both desktop and mobile Gmail — colors/fonts can render slightly differently across clients, and bold-gray sometimes looks too light on mobile. Adjust if needed.
