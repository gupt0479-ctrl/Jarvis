So: use Apollo/Hunter (or just better manual search) only to close the discovery gap in Step 4, keep every message single-recipient and hand-written, keep the existing Contact-note-per-relationship structure exactly as it is. **No new build required** — this is a discovery-tool swap inside an already-correct system, not a new outreach engine.
