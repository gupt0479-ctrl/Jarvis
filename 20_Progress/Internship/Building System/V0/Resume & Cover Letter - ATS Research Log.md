# Resume & Cover Letter — ATS Research Log
==Running, cross-session log of every external resume/cover-letter/ATS resource found for the goal in [[Resume Alteration Standard]] and [[Cover Letter Alteration Standard]]: writing application documents that pass automated screening at the specific ATS platforms and companies this loop's own dossiers come from, with zero fabricated citations.== Each session appends a dated section below — never overwrites a prior session's findings. Classification follows the Standards' own §4 source-register tiers, extended with one clarifying tier this research surfaced a real need for.

## Source Tiers (extends the Standards' §4 definitions)
- **(a) Primary/official** — the company's or ATS vendor's own published page/doc/video, fetched and read directly, not paraphrased by a third party.
- **(a-assoc) Professional association standard-setter** — not a single employer, but the body that sets the standard many university career centers themselves cite (here: NACE). Treated as authoritative, one notch below a named employer's own statement, above a single university's paraphrase of it.
- **(b) University career-service guidance** — a specific university's own career center page, cited to that office.
- **(c) Third-party advisory** — a guide, blog, or tool not published by the employer/vendor/association itself. Split further here because this session found the split matters:
  - **(c-1) Empirically-tested tool**, cited by name, that at least one university career center endorses for student use (here: Jobscan, endorsed by WGU's career office) — more weight than an anonymous blog, still never citable as an "official" standard.
  - **(c-2) SEO/AI-generated ATS-advice sites** (resumeats.net, applyarc.com, resumeadapter.com, resumeoptimizerpro.com, stylingcv.com, cvai.dev, withresumeai.com, resumegeni.com, quantvault.org, quantt.co.uk, openquant.co, profileelevate.com, thetailorcv.com, atsverification.com, askcruit.com, resumefast.io — all found this session). These sites often *cite* real vendor docs (several explicitly footnote Greenhouse's own support articles) but are not the vendor's own voice, republish claims about ATS platforms whose own docs were never found (Workday — see gap below), and exist to sell a resume tool. Use only for a claim independently cross-checked against an (a)/(b) source in this log; never cite one standalone as "how Greenhouse/Workday works."

## Session 1 (2026-08-29) — findings

### A. ATS vendor primary docs — the three platforms `internship-research-loop` already integrates ([[20_Progress/Internship/Building System/Research Loop - Resources]])
This is the highest-leverage category found this session: these are the *exact* systems this loop's own dossiers pass through before a human ever sees them, and two of the three (Greenhouse, Ashby) publish real candidate-facing documentation.

**Greenhouse (a)** — verified live 2026-08-29:
- [Supported formats for resumes, cover letters and other candidate uploads](https://support.greenhouse.io/hc/en-us/articles/360052218132) — accepts `.doc`, `.docx`, `.pdf`, `.rtf`, `.txt`; uploads up to 100MB.
- [Unsuccessful resume parse](https://support.greenhouse.io/hc/en-us/articles/200989175) — Greenhouse's own named parse-failure causes: files >2.5MB, graphics/photos/word art, image-only uploads (scanned docs), tables/headers/footers/text boxes, columned layouts, unclear/inconsistent sections, company names without a legal suffix (Inc./Co./LLC), incomplete job titles.
- **Direct takeaway**: single-column, text-based (not scanned) PDF or DOCX under 2.5MB, standard section labels, contact info in the document body, is not advice — it's Greenhouse's own stated failure-mode list.

**Ashby (a)** — verified live 2026-08-29, and this **overturns the third-party framing** found alongside it:
- [Bulk Import: Email Import — file requirements](https://docs.ashbyhq.com/bulk-import-email-import) — Ashby's own stated rule: uploaded file must be a **PDF** (image formats like JPEG/PNG/GIF are ignored, not parsed) and must contain a name plus one identifier (email, phone, or a social link) or no candidate profile gets created.
- [Reviewing 1500 resumes in 6 hours with AI-Assisted Application Review](https://www.ashbyhq.com/blog/recruiting/ai-assisted-application-review-in-practice) — Ashby's own blog, describing its actual mechanism: it does **not** parse resumes into rigid structured fields the way Greenhouse/Workday do. It keeps the candidate's original uploaded file, and its AI reads that file against recruiter-defined criteria ("must-have / should-have / nice-to-have"), producing a Meets/Does-Not-Meet judgment **with a citation to the exact evidence**, which a human recruiter reviews and can override — explicitly not an autonomous reject.
- **Direct takeaway, and a correction worth stating plainly**: several third-party (c-2) sites claim Ashby "reads two-column layouts fine" and treat it as immune to formatting parse failures — true for the *file-preview* half of Ashby's system, but the file must still be a real PDF with a name+identifier or no profile is created at all per Ashby's own docs above. Don't relax the single-column/standard-format baseline for Ashby-posted roles; the risk it removes is field-scrambling, not existence.

**Lever** — not checked this session. `internship-research-loop` already has a live Lever integration ([[20_Progress/Internship/Building System/Research Loop - Resources]], "nine sources now") — Lever's own candidate-facing upload/parsing documentation is a named gap, see Session 2 Task List.

**Workday** — genuinely searched, not found. Every Workday-specific claim in circulation (single-column, MM/YYYY dates, standard headings, "Illuminate" AI layer since Sept 2024, semantic + exact-keyword matching) traces only to (c-2) sites in this session — none linked to or quoted from a Workday-owned candidate help page. This is a real gap, not a skipped step: Workday's public-facing candidate documentation may simply be thin (it's a much more enterprise/HR-facing product than Greenhouse). Flagged for Session 2, not force-cited as (a).

### B. Official company hiring guidance (a)
These are the two gaps the Resume Alteration Standard's §4 explicitly flagged as unsourced as of 2026-08-28 ("Google's XYZ method," "an Amazon resume template") — both are now real, findable, (a)-tier sources, not templates but genuine official guidance:

- **Google** — [Create Your Resume for Google: Tips and Advice](https://www.google.com/about/careers/applications/videos/google-resume-tips-and-advice/) — hosted directly on `google.com/about/careers`, Google's own recruiting-team video. States: PDF preferred, no unusual fonts/colors, 1 page for business/internship roles, 2 pages max for engineering roles, clearly delineated standard sections, education first for students, and gives the **XYZ formula verbatim as Google's own framework**: "Accomplished [X] as measured by [Y] by doing [Z]." This is the real citation the Standard was missing — "Google's XYZ method" is genuinely Google's own stated framework, not a third-party myth, and can be upgraded from (c) to (a) in the Standard's register on that basis.
- Corroborating secondary reporting (c-2, not the citation itself, useful only as color): [Business Insider, Google university-recruiting panel](https://www.businessinsider.com/google-internship-resume-tips-advice-recruiters-past-experience-2021-10) (named recruiters Katarzyna Kamińska, Emily Salkey — no single "perfect format," 30–40 second recruiter read time, past experience is a must-have); [CNBC, Google's Head of Recruiting Brendan Castle](https://www.cnbc.com/2021/12/13/googles-head-of-recruiting-the-one-rule-to-writing-a-strong-resume-.html) (tell your story: role, contribution, biggest impact, at each entry).
- **Amazon** — [Amazon job application: Resume writing tips](https://www.aboutamazon.com/news/workplace/amazon-job-application-resume-writing-tips) — published on `aboutamazon.com`, Amazon's own company site, quoting named Amazon recruiting staff (Bhavishya Lingam, senior recruiting business partner, Amazon Stores; Patti Cudney, senior recruiting business partner). States: well-organized, straightforward language, quantified/measurable results, streamlined for readability; don't build a wholly new resume per role, but align accomplishments to the JD's "Basic and Preferred Qualifications" keyword sections specifically. **Precision note**: this is official *guidance*, not a downloadable "Amazon resume template" — the Standard's §4 language should be corrected to say "official guidance found," not imply a template exists, since none does.

### C. University career-service guidance (b) and the association that sets their shared standard (a-assoc)
- **NACE** (National Association of Colleges and Employers) (a-assoc) — [Career Readiness Competencies](https://naceweb.org/career-readiness/competencies/career-readiness-defined) defines the 8 competencies (career & self-development, communication, critical thinking, equity & inclusion, leadership, professionalism, teamwork, technology) that the university sources below build their own resume rubrics on top of. NACE's own bullet-writing formula, cited across multiple university handouts found this session: **Action Verb + Task/Skill + Result**.
- **University of Florida Career Connections Center (b)** — [Resume Guide](https://careerhub.ufl.edu/resources/resume-guide/) — NACE-aligned bullet-writing guidance; explicit instruction to customize resume, cover letter, and supplemental questions per posting, not just the resume.
- **University of Michigan Career Center (b)** — [Cover Letter Resources](https://careercenter.umich.edu/content/cover-letter-resources) — 3–4 paragraphs; one page max; font 10–12pt matching the resume; margins 0.5–1in; left-justified, starting no more than 2in from the top; avoid clichés ("...make me an outstanding candidate"); if emailed, the letter can be the email body itself.
- **UT Dallas Career Center (b)** — [Creating a Cover Letter](https://career.utdallas.edu/career-resource-library/resume-and-cover-letter/creating-a-cover-letter/) — explicit ATS framing: no templates, invisible text boxes, images, QR codes, color, or shading; start from a blank document for a true text-only version; standard non-decorative fonts (Times New Roman, Calibri, Arial), black ink, 10.5–12pt; margins 0.5–1in; one page max.
- **Penn State Engineering Career Services (b)** — [Cover Letters](https://career.engr.psu.edu/students/basics/cover-letter.aspx) — always include a cover letter when the option exists; block-text business-letter format; same typeface as the resume; three parts (intro/body 1–3 paragraphs/conclusion); use JD keywords in the body to show understanding of the role, not just to pattern-match.
- **A specific university's internal handout citing NACE (b, origin university not fully confirmed)** — [a career-services PDF hosted on uConnect's CDN](https://cdn.uconnectlabs.com/wp-content/uploads/sites/33/2022/06/CARS-669-PT-Resume-NACE-Updates-2.pdf) — 1–2 pages (2nd page only if full), 10–12pt Calibri/Times New Roman/Arial, must be scannable in 15 seconds, avoid raw Microsoft Word templates (hard to edit cleanly), PDF for upload/email to preserve formatting, references go on a separate page never inside the resume. **Flag**: this is a real university handout (the "CARS-669" naming and uConnect CDN path both suggest a specific career-services platform tenant) but the exact university wasn't confirmed from the URL alone — treat the content as (b)-credible since it matches every other (b) source's rules independently, but don't cite it by a specific university name until that's confirmed.

### D. Third-party, empirically-tested tool endorsed by a university career office (c-1)
- **Jobscan** ([jobscan.co](https://www.jobscan.co/)) — [endorsed directly by Western Governors University's career office](https://careers.wgu.edu/resources/jobscan-information-for-faculty/) for student use, with WGU's own stated target: aim for a 75% match rate, not 100% ("your resume might end up sounding unnatural or keyword-stuffed" — WGU's own words, not Jobscan's marketing). Jobscan's own [October 2023 product update](https://www.jobscan.co/blog/product-update-october-2023/) documents that it moved away from exact-keyword-only matching to word-variation detection ("managed"/"manager"/"management" now count as related), citing this as a deliberate response to real ATS evolution, not a marketing claim about ATS behavior it doesn't operate.

### E. Keyword density and "stuffing" — the concrete answer to the character/keyword-limit question
Cross-checked four independent (c-1)/(c-2) sources plus one indirect SEO-industry citation; they converge tightly enough to treat as a working rule despite none being an (a) source:
- **No verified universal density percentage exists** — every source that claimed a specific percentage ("2% density," "0.8–1.2% per keyword") also stated in the same breath that chasing a percentage number is itself the failure mode (this shows up independently in [thetailorcv.com](https://thetailorcv.com/blog/resume-keyword-density-guide), [atsverification.com](https://atsverification.com/blog/resume-keyword-density-how-much-too-much/), and [askcruit.com](https://www.askcruit.com/resume/ats/avoid-keyword-stuffing), which also cites Google's John Mueller stating keyword density has never been a search-ranking factor, applied here by analogy to resume ATS).
- **Convergent working rule**: 2–4 total mentions per top-priority JD keyword across the whole document (once in Skills as a scannable item, once in the Summary if central to the role, 1–2 times in Experience bullets each attached to a specific task/result) — never the identical phrase repeated back-to-back with no new context, which is the actual stuffing signal these tools detect, not a raw count.
- **askcruit.com's specific number worth logging**: candidates who use the exact job title naturally on their resume are, per Jobscan's own research (cited by askcruit, not independently verified here), 10.6x more likely to get an interview than those who omit it or force it in unnaturally.

### F. Cover letter length — convergent answer
Five sources (Michigan (b), UT Dallas (b), Penn State (b), Indeed, Resume.io) independently converge: **one page or less, 250–400 words, 3–4 paragraphs**, with entry-level/internship candidates trending toward the 200–300 end. This matches — and now sources — the 250–350 word default already written into [[Cover Letter Alteration Standard]] §3 before this research pass; that section's number didn't need correcting, it just didn't have a citation yet.

### G. Niche/quant-firm-specific guidance (Jane Street, Citadel, HRT, Two Sigma) — real gap, not resolved this session
Searched directly since these are named target programs in [[Internship Tracking Dashboard — 2027 Calendar, Programs, & Application Pipeline]]. **Found nothing at (a) or (b) tier** — every quant-resume source this session found (quantvault.org, quantt.co.uk, openquant.co, profileelevate.com) is (c-2): third-party quant-career blogs, none citing or linking to Jane Street/Citadel/HRT/Two Sigma's own published application guidance. Recurring claims worth testing against a real (a) source if one turns up: one-page LaTeX resume as "informal standard" in quant finance (Jake's Resume / moderncv templates named repeatedly), GPA inclusion threshold quoted higher than general tech (~3.7 vs. ~3.5), rolling review favoring early submission. **Do not treat any of this as verified company policy** — it's pattern-matched convention from candidates and advisory sites, not from the firms themselves. Real target for Session 2: check each firm's own careers/FAQ page directly (jane-street.com, citadel.com, hudsonrivertrading.com, twosigma.com) before relying further on these.

## Session 2 (2026-08-29) — primary-source gap checks

### A. Lever candidate resume parsing (a) — resolved
- **Lever Help Center** — [Understanding resume parsing](https://help.lever.co/hc/en-us/articles/20087345054749-Understanding-resume-parsing) and [Adding and deleting resumes](https://help.lever.co/hc/en-us/articles/20087357076253) — Lever's own documentation, verified live 2026-08-29. Lever extracts readable resume content into profile fields including name, work history, organization, and contact information. It parses Word/DOCX, PDF, RTF, Corel WordPerfect, HTML/MS Office HTML, and Open Office/ODF; it cannot parse JPG/PNG. Lever's own candidate-side test is practical and specific: if text cannot be highlighted, the file is likely not parseable; it identifies scanned documents as a common case and suggests converting them. Its uploader accepts common resume types up to 10MB and can store a cover letter or portfolio as an additional resume document.
- **Direct takeaway:** text-based/selectable PDF or DOCX remains the interoperable baseline. This is a new (a) source for the rule; it does **not** say that keyword repetition, keyword density, or conventional section headings affect matching.

### B. Workday public documentation (a), but not candidate-facing — narrowed and resolved
- **Workday HiredScore** — [Concept: HiredScore Grades](https://doc.workday.com/hiredscore/en-us/workday-hiredscore/recruiter-productivity-/concept--hiredscore-grades.html) and [Concept: Candidate Profiles](https://doc.workday.com/hiredscore/en-us/workday-hiredscore/recruiter-productivity-/concept--candidate-profiles.html) — Workday's own public product documentation, verified live 2026-08-29. HiredScore assigns grades based on how well a resume matches skills and qualifications in the job description; it does not grade a candidate with no resume, an unsupported format, or no JD. Its supported resume attachments are DOC/DOCX/PDF/RTF/TXT. Candidate Profiles describes parsed/smart resumes, JD-to-resume side-by-side comparison, and keyword search of an original resume.
- **Important scope limit:** the Grades document expressly says HiredScore does **not** assign grades on a *campus or graduate requisition*. It is therefore evidence that Workday products can parse and match resumes for some requisitions, not evidence that a Workday-hosted internship is automatically AI-scored or ranked.
- **Candidate-facing answer:** no Workday-owned public candidate help/FAQ source explaining resume parsing or scoring was found after direct searches of `workday.com`, `doc.workday.com`, and `community.workday.com`. The real official sources are product/recruiter-admin documentation above; do not represent third-party claims (specific headings, date syntax, semantic scoring, or "Illuminate") as candidate-facing Workday policy.

### C. Keyword-density cross-check — primary evidence changes the boundary, not the number
- Lever's official parsing document describes extraction from *readable* files, with no keyword matching or density prescription. Workday HiredScore officially describes JD skills/qualifications matching and keyword search, but gives no keyword-frequency, percentage, or anti-stuffing threshold; it also excludes campus/graduate requisitions from grades.
- **Corrected evidence rule:** no primary ATS-vendor source supports the Session 1 working heuristic of 2–4 mentions per top keyword. Keep the operational principle—use a JD's terminology only where it truthfully describes demonstrated work—but treat any count as (c)-tier advisory, never as ATS-vendor fact. There remains no verified universal keyword-density percentage.

### E. Named early-talent-program guidance (a)

- **LinkedIn First Play:** no LinkedIn Careers/First Play document-format guidance was found. A LinkedIn employee's official-platform post announces applications and expressly declines to advise applicants how to stand out; it is not a formal recruiting standard and is not entered as one.

- **Bloomberg:** [Engineering: Student Application Process](https://www.bloomberg.com/company/careers/application-process/engineering-student/) is (a) and genuinely student-specific: Bloomberg will review the resume and discuss technical projects, contributions, and impact. - **NASA OSTEM:** [Intern FAQ](https://www.nasa.gov/learning-resources/internship-programs/intern-frequently-asked-questions/) and [5 Tips to Craft a Standout NASA Internship Application](https://www.nasa.gov/learning-resources/tips-to-craft-standout-internship-application/) are (a) and OSTEM-specific. OSTEM does **not** accept a resume-file upload; it asks candidates to enter their experience, skills, interests, and relevant background directly, using an existing resume as reference. NASA mentors specifically emphasize a project-aligned personal statement, academic work/GPA/coursework/projects, extracurriculars, and both technical and nontechnical skills. This is application-field guidance, not a resume-format rule. (NASA's separate Pathways guidance about a narrative CAR-format USAJobs resume must not be transferred to OSTEM.)

### G. Cover-letter-specific target-company guidance (a) — found, with careful scope

- **Capital One:** [How to Write a Cover Letter for a Job](https://www.capitalone.com/learn-grow/life-events/how-to-write-a-cover-letter/) is (a) company-published general guidance, not a Capital One recruiting requirement: tailor to company/role, introduce the role and strengths, make the qualification case in the body, connect experience to the organization, and avoid repeating the resume. It is usable as general (a) advice only with that distinction stated.

For those programs, no cover letter should be presumed required; follow the specific live posting/application instead.
