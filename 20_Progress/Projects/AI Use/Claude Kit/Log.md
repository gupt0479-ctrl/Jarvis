## [2026-07-30] sync | Unison chosen over rclone bisync (researched, not assumed), sync mechanism built and tested end-to-end
- Researched Unison directly from its own manual (`bcpierce00/unison`, fetched, not recalled from training) before switching off the earlier `rclone bisync` plan. Reasons it wins for this pairing: syncs two local directories from one process with no ssh/remote/version-matching risk (both replicas — repo on WSL ext4, Jarvis mirror on `/mnt/d` — are local paths from one WSL session); `-batch` mode's default is to **skip and report** genuine conflicts rather than `rclone bisync`'s default "newer wins" silent overwrite; packaged for Ubuntu/available as a static no-root binary; zero cost either way.
- **Installed for real**: this sandbox's `sudo` has no usable password, so installed Unison's official static Linux binary (`v2.54.0`, from GitHub releases) to `~/.local/bin/unison` instead — no root needed. Scripted as `second-brain-claudekit/50_Claude/scripts/install_unison.sh`.
- **Built and tested `second-brain-claudekit/50_Claude/scripts/sync-jarvis.sh`** — syncs exactly `.claude/agents`, `.claude/commands`, `.claude/hooks`, `.claude/settings.json`, and root `CLAUDE.md` between the repo and this new [[20_Progress/AI/Claude Code/second-brain-claudekit/Setup|second-brain-claudekit]] folder, via Unison's `-path` preference (no ignore-regex needed). First real run failed (`Failed to set permissions ... rwxrwxrwx` — DrvFs can't hold POSIX permission bits); fixed with Unison's `-fat` flag, documented for exactly this filesystem class. Re-ran clean: 5 items transferred, 0 failed.
- **Tested the reverse direction for real**: edited `.claude/commands/today.md` on the Jarvis side, ran the sync, confirmed the edit landed back in the repo.
- **Tested a genuine conflict for real**: edited the same file differently on both sides between syncs, ran the sync — Unison skipped it and reported `contents changed on both sides` (exit 1), **neither side was overwritten**, both edits verified intact afterward. This is the actual safety property the tool-choice argument rested on, reproduced rather than assumed.
- Created [[20_Progress/AI/Claude Code/second-brain-claudekit/Setup|second-brain-claudekit/Setup.md]] (a live-synced folder, not a stale hand-copy like the other project folders here) and added it to [[20_Progress/AI/Claude Code/MOC|MOC.md]]'s project table and notes.
